## Example: How do I Manage Distribution Groups?
You can manage distribution groups in Microsoft 365 using the Admin Center, Exchange Admin Center, or PowerShell.
Typical management actions include:

Adding/removing members
Assigning group owners
Setting delivery restrictions
Enabling message moderation
Where to manage:

Admin Center: Easy UI for group membership and settings.
Exchange Admin Center: Advanced options for permissions and moderation.
PowerShell: Fast, scalable changes using scripts.

Learn more:

https://learn.microsoft.com/en-us/exchange/recipients-in-exchange-online/manage-distribution-groups
